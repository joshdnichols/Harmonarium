# Harmonarium
A python app that creates permutations of chords with great flexibility and engraves the scores in LilyPond.

See the User Guide for what it can do. Initial builds for Windows and Mac forthcoming.

# APP STYLE
The app is interfacing with python through a web app viewer. If you run the `.py` file by the same name, it will launch in your browser. The build kit has separate instructions for building a mac and a windows version. You can build the app yourself, with a few things to note below

# DEPENDENCIES
You must obtain the latest stable release of python, which at the time of this writing is v. 3.15. You should install it yourself, and system wide (not local user). That's the only catch. If you would prefer not mess with installing a bunch of dependencies, then look to the official releases of this app for a windows and mac version. 

# WARNINGS
